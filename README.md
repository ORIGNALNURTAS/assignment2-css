# Assignment 2 — Advanced CSS (Flexbox & Grid)

Three tasks, each a self-contained static page (plain HTML + CSS, no frameworks, no JS, no media queries):

- `task1/` — Geometric composition, CSS Grid only (6×6 grid).
- `task2/` — Component library, Flexbox only (navbar, cards, pagination, comment, pricing).
- `task3/` — Same markup, three layouts (grid / list / magazine) switched with CSS-only radio buttons.

## Running locally
Just open `task1/index.html`, `task2/index.html`, `task3/index.html` directly in a browser
(or open `index.html` in the project root, which links to all three).

## Publishing with GitHub Pages (optional but handy for the defense)
1. Push this folder to a GitHub repository (see steps below).
2. Repository → **Settings → Pages**.
3. Under "Build and deployment", set **Source: Deploy from a branch**, branch **main**, folder **/(root)**.
4. Save. GitHub gives you a link like `https://<username>.github.io/<repo>/` a minute later.
5. Put that link (and the repo URL) in your report.
